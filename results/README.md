# 真实数据运行结果

数据：NCBI GEO GSE272159；结构注释：课程工作簿 Supplementary Tables 4/5/6。文件哈希见 `provenance.json`。
所有原始矩阵和完整逐窗口图仍在本地 `data/raw/` 与 `outputs/`，本目录保留便于审阅的小型结果。

## 任务一：已知结构识别

留出集准确率 0.746，宏平均 F1 0.642；结构数训练/验证/测试为 220/55/69。
CHID 样本少，逐类召回请结合混淆矩阵阅读。

## 任务二：新结构候选

扫描 1812 个窗口，入选 905 个；按预设规则得到 5 个未注释候选。已知结构跨重复筛选后召回 0.901。
较严格的预设阈值（前 20%、重复相关至少 0.3）产生 0 个新候选；对该参数选择应做进一步敏感性验证。
形态特征区分已知注释与背景的空间留出 AUC 为 0.598，证据较弱。
这些是计算候选，不是经实验确认的新结构。

## 任务三：全基因组轨道

生成 465 张 10 kb 区间图，覆盖 WT 37℃、44℃ 和 rifampicin 25。

## 任务四：实验条件变化

rifampicin 25 相对于 WT 的归一化结构强度平均变化：

- CHID（26 个）：-0.530
- CHIN（250 个）：-0.454
- OPCID（68 个）：-0.543
两条件各使用两个生物学重复；WT 重复对照汇总见 `task4_repeat_class_summary.csv`。

## 任务五：超分辨

测试窗口 208 个；PSNR 双线性/CNN 为 18.901/20.843，SSIM 为 0.118/0.141。CNN 相对双线性提升 PSNR 1.942、SSIM 0.023。模型使用残差块和接触边界梯度损失；低分辨率输入先对原始接触计数合并 bin，再单独归一化，避免把高分辨率目标统计量泄漏到输入。
低分辨率输入由 Micro-C 合并 bin 模拟，不能外推到独立 Hi-C。

## 任务六：三维重建

929 个 5000 bp bin；接触与反距离 Spearman 相关为 MLP 0.595、MDS 0.313。
MLP 使用 MDS 初始化，因此两者不是独立建模路线；坐标并非唯一的真实物理构象。
